# pannellum-test

The NSYNK office (17th floor), 38 places from a Leica BLK360 scan, as a 360° tour with [Pannellum](https://pannellum.org) 2.5.7.

- `v2.html`: the test page. The **Options** panel (top right) switches Pannellum's own config options and API calls.
- `index.html`: the first, plain version.

Static files only, no build step. Generated from the NSYNK project's data (`tour.json`, `tour-v2.json`).
